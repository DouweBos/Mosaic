# Security Policy

## Supported versions

Only the latest version of Mosaic gets security fixes.

## Reporting a vulnerability

Please don't open a public issue for security problems. Report them privately instead:

- through [GitHub private vulnerability reporting](https://github.com/DouweBos/Mosaic/security/advisories/new), or
- by email to [douwe@douwebos.nl](mailto:douwe@douwebos.nl).

Include what you found, how to reproduce it, and the Mosaic version. You'll get a reply within a few days, and a fix or a plan once the report is confirmed. Credit is given in the release notes unless you'd rather stay anonymous.
